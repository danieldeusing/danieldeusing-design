# Runtime

Reference for the `danieldeusing-design` skill. Read it before a page calls the runtime.

## Runtime — `runtime/*.js`, dependency-free ESM, tree-shakeable

`@danieldeusing/design/runtime` re-exports every function below; `@danieldeusing/design/runtime/<module>`
imports one module. Nothing runs at import — a server-side render can import the barrel — and every
`init*()` is safe to call once per page: a delegated listener or a MutationObserver reaches what is
rendered later, so none needs a second call.

| Function | What it does |
| --- | --- |
| `applyStoredTheme()` / `setTheme()` / `getStoredTheme()` | Apply + persist the theme. **Pre-paint from `<head>`.** |
| `applyTheme(theme, { faviconHref })` / `THEMES` / `THEME_BACKGROUNDS` | `applyTheme()` sets `html[data-theme]`, the `<meta name="theme-color">` and, with `faviconHref`, the favicon, and does NOT persist (`setTheme()` does). `THEMES` is the four names in menu order; `THEME_BACKGROUNDS` maps each to the background it writes into `theme-color`. |
| `initThemeSwitcher()` | Wires `[data-theme-value]` buttons and `[data-theme-label]`, and marks the theme in force: `role="menuitemradio"` + `aria-checked` inside a `.dropdown-panel`, `aria-pressed` elsewhere. **The ✓ is this call's**: since 0.60.0 no CSS rule marks the current theme, so a switcher without it shows four identical items (`components.md`). |
| `initResolutionZoom(1920)` | **Deprecated in 0.29.0 — does nothing.** From 0.29.0 wide-screen scaling was the fluid root font size in `tokens.css`, and since 0.56.0 there is no wide-screen scaling at all, so there is no script to call and no pre-paint flash to avoid. Still exported so a pin can be bumped without editing `<head>` in the same commit. Delete the call and any inline zoom IIFE with it. |
| `initDropdowns()` | Every `<details class="dropdown">`, now and rendered later: a panel of rows becomes an APG menu (roles, arrow keys, Home/End, typeahead, Escape back to the summary, a labelled section a `role="group"`), one open at a time, click-away. It re-asserts the attributes it owns when a renderer strips them (`components.md`). |
| `attachMenuKeys(panel, { onClose, returnFocusTo })` | The same menu keys for a menu the page builds and places itself — a context menu, a menu under a button. Returns a function that detaches them. |
| `initFolds()` | A printout carries what the folds were holding: every closed `<details>` opens for print and closes again after, a fold the reader opened stays open, and a menu is left alone. |
| `initSelects()` | Replaces the OS dropdown on every `<select>` with the estate's listbox — the one component CSS alone can never reach, because the option list is painted outside the page. **Markup contract is nothing**, and there is no opt-out; the `<select>` stays authoritative (value, form submission, `input`+`change`, `aria-invalid` and `aria-describedby` mirrored onto the trigger). `data-filter` makes it a filter dropdown; a filter with more than 20 options, or any select with `data-search`, gets a search row, and its popup is then a dialog (`filters.md`). Selects rendered later are picked up by a MutationObserver. Keyboard is the ARIA APG select-only combobox. |
| `positionPopup(panel, anchor, { gap, edge, minWidth, align, side })` | Where a popup list goes: under its anchor, or over it when that is where the room is, clamped to the viewport. `anchor` is an element or a point (a context menu's pointer). Writes only inline position; returns `{ side }`. |
| `initSearchFields()` / `markPending(field, ms)` | A `.search-field`'s clear button and Escape, and the pending line a debounced search draws while it waits. The page owns the query. |
| `initSortControls()` | A `.sort-ctl`'s direction toggle; fires `sortchange` (`detail: { field, dir }`) on the control. The page sorts. |
| `initTableTools()` / `applyTableView()` / `resetTableView()` | The table engine on every `<table data-table-tools>` (a `data-table-id` is optional here; it keys the remembered view): a `.filter-bar` with a `.search-field` above the table, per-column sort and a filter menu (with the popup ✓ and its arrow keys) in the `<th>`, a badge naming the value on a filtering column, a result count, and the empty and loading states. Detaches filtered-out rows so the pager slices the matching set. The view is remembered per table under `table-view:<id>` when the table has an id; a renderer that re-renders the table keeps its box and count (`tables-and-forms.md`). |
| `initPickCells()` | A press anywhere in a table's `.pick` cell toggles its checkbox — the cell is the 44px target under a coarse pointer, not the box. |
| `initBurgerNav()` | Mobile burger (breakpoint 48rem) with the footer folded in. |
| `initLsNav()` | Call it on EVERY page, rail or none: it measures the chrome — a `.bar-stack` (banner + header) or the header, and a `.page-toolbar` — into `--ls-nav-top` / `--ls-nav-bottom` and `--sticky-top`, and a ResizeObserver re-measures when a banner goes. With a rail it also wires the rail's show/hide. The top is the header's **bottom edge** (`getBoundingClientRect().bottom / zoom`), not its height — those agree only while nothing sits above the header, and cockpit's alert banner mounts as the first child of `<body>`. A rect is visual px and a CSS length is re-multiplied by any ancestor `zoom`, so **convert, don't avoid** (0.13.0; before that a 73px banner buried the rail's own toggle). Re-measured on `scroll` too, because a sticky header's bottom edge moves as the banner scrolls away. |
| `initTerminal()` | The `$ command` typing animation; no-ops under reduced motion / `html.anim-off`. Fires `term:contentdone`. |
| `initAnimToggle()` | Wires `[data-anim-toggle]`, persists `localStorage["anim"]`; `data-label-on` / `data-label-off` and `[data-anim-label]` let the toggle's words follow the state. |
| `initToc()` | A table of contents' scroll-spy: the entry for the section being read carries `aria-current="true"` (`chrome.md`). Returns `{ destroy() }`. |
| `initDiagramZoom(".diagram")` | Click / Enter / Space opens a diagram full-screen; wheel-zoom about the pointer, drag-pan, `+ - 0`, Escape closes. Clones the svg — mermaid re-runs against the nodes it rendered, so moving the original is how a diagram silently stops updating. |
| `initMinimap({sections})` | Builds the left-gutter minimap: one bar per section, scroll-spy included, bar length by heading depth. Markup contract is nothing. Returns `null` for fewer than two sections — a map of one place is not a map — and on a page that has a table of contents: a page shows a TOC or a minimap, never both. |
| `initTableScroll()` | Gives every unwrapped `<table>` a `.tablewrap` parent so a wide table scrolls itself instead of scrolling the whole page sideways. **The markup contract is nothing** — author a plain `<table>`; already-wrapped tables are left alone, so it is never a migration. **Tables rendered later are wrapped too** (0.23.0, MutationObserver), so a page that fetches its rows needs no second call. Colour the right-edge fade with `--tablewrap-fade` when the wrapper does not sit on `--background`. |
| `initTablePagination()` | Pages every `<table data-table-id>` to 20 rows, with a 5/10/20/50/100/200 picker remembered per table. **Markup contract is one attribute**, and a table without it is left alone — the id cannot be guessed without silently reassigning readers' settings when a table moves. It has **no sort and no filter**: it hides all but one window of rows a page has *already* filtered and sorted, so the order is filter → sort → slice over the full set by construction. Turning the page writes `hidden` on rows and rebuilds no markup, so it composes with in-place patching. Tables rendered later are picked up by a MutationObserver. |
| `pageWindow(total, size, page)` / `normalizePageSize(raw)` / `applyPageWindow(rows, from, to)` / `PAGE_SIZES` / `DEFAULT_PAGE_SIZE` | The pager's arithmetic, for a page that pages something that is not a table. `pageWindow()` clamps the page into range and returns `{ page, pageCount, from, to }` (a half-open range); `normalizePageSize()` turns anything stored that is not one of `PAGE_SIZES` (5, 10, 20, 50, 100, 200) into `DEFAULT_PAGE_SIZE` (20); `applyPageWindow()` sets `hidden` on the rows outside the range and touches no row that is already right. |
| `initTooltips()` | One viewport-clamped panel for every `[data-tip]`, including nodes rendered later; Escape closes it, and it moves into an open dialog's top layer. Shows **instantly**, on hover and focus, and sets `aria-describedby` on the anchor while open (0.26.0) so it is announced the way a `title` is. `src/tooltip.css` counterpart. **This replaces the native `title` — see "A hover is `data-tip`" in `components.md`, next to this file.** |
| `initDialogs()` / `openDialog(dialog, opener)` / `closeDialog(dialog, value)` | `dialog.dialog` opened modally: `[data-dialog-open="<id>"]` opens, `[data-dialog-close]` closes (its value the `returnValue`), a press on the backdrop closes a plain dialog, focus goes in and comes back. A footer that is committing (`aria-busy`) locks its closers (`overlays.md`). |
| `initNotices()` | The dismiss button on a `.notice`, delegated. |
| `initCopyButtons()` | `[data-copy]` on a button copies the `.cmd-text` beside it, a literal, or `data-copy-from`'s text, and says whether it worked (`content.md`). |
| `initTabs()` | The APG tab bar on every `.tabs[role="tablist"]`, now and rendered later: selection, arrow keys, `data-tabs-hash` deep links, nesting, and a `tab-activated` event (`detail: { panel }`). A renderer that re-renders the row writes the current selection; the runtime re-asserts `aria-selected` and `tabindex` if a patch strips them (`data.md`). |
| `parseInstant()` · `stampParts()` · `formatStamp()` · `formatAgo()` · `formatDuration()` · `whenHtml()` · `initRelativeTimes()` | An instant in the VIEWER's zone and how long ago it was: `whenHtml(iso)` is the `.when` cell, and `initRelativeTimes()` keeps every `[data-ago]` label true while the page is open (`data.md`). |
| `renderLineChart(mount, rows, opts)` / `renderBarChart(mount, rows, opts)` | A line or bar chart drawn at the size it is shown, every series with a non-colour cue; the series' hue is `series[].hue`, one of the twelve `--cat-*` names (`data.md`). |
| `findFlushBlocks(root, { blocks, tolerance })` / `STACKED_BLOCKS` | Every pair of stacked blocks with 0px between their border boxes, as `[{ upper, lower, gap }]` — the check a page-level browser test runs for the rhythm rule `base.css` cannot see everywhere. A fold after a fold, and a lower block carrying `data-flush`, are not reported (`foundations.md`). Reads the DOM only when called. |
| `findMisplacedFilters(root, { tolerance })` | Every filter control that breaks the filter rule, as `[{ element, reason }]`: a filter, sort or chip set outside a `.filter-bar` (a table header, a `.dropdown-panel` and a chip set of `.chip--remove` values excepted, a dialog not), a lead after a control or a row's first lead off the left edge, a row's controls short of the right edge, an optional filter holding a value without its active mark and ×, a required one showing a ×. Skips what is not rendered (`filters.md`). Reads the DOM only when called. |
| `renderTickStrip()` / `initTickStrips()` | The ticker strip from the `window.__ddTicks` registrations, re-rendered every second from memory and refreshed through `window.__ddTickRefreshers` (`data.md`). |

The runtime is progressive enhancement: with JS off, content is visible and the theme is `warm`.
